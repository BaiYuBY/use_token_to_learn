怎么知道一个模型好不好？这一页用真实训练的小模型和可控的模拟，看清四件事：困惑度衡量什么、什么时候能比较；基准分数有多少噪声、排行榜有多可靠；用大模型当评委有哪些偏差；以及测试题泄漏进训练数据（污染）会怎样抬高分数、怎样发现。 How do you know whether a model is good? With small models trained for real and controlled simulations, this page shows four things: what perplexity measures and when it can be compared; how noisy benchmark scores are and how reliable leaderboards are; the biases of LLM judges; and how test questions leaking into training data (contamination) inflate scores, and how to catch it.

1困惑度：逐词看模型有多“意外”Perplexity: how surprised the model is, word by word

困惑度 = exp(每个词元的平均负对数似然)。可以理解为：模型平均在几个选项之间犹豫。下面是 06 章小语言上训练的词级模型，对测试句子每个词给出的概率（颜色越深越意外）。点一个词，看模型在那个位置预测的前 5 名。 Perplexity = exp(average negative log-likelihood per token): roughly, how many options the model is torn between on average. 2基准分数是抽样：排行榜有多可靠A benchmark is a sample: how reliable is a leaderboard?

10 个模型，真实准确率（在所有可能的题上）从 55% 到 69%，相邻约差 1.5 分。每次从题库里抽一套基准题，按项目反应理论让模型作答：答对概率 = sigmoid(能力 − 难度)。看看抽到的题不同，排行榜会怎样变。蓝条是 95% 置信区间，橙线是真实准确率。 10 models whose true accuracy (over all possible questions) runs from 55% to 69%, neighbours about 1.5 points apart. 3用大模型当评委：偏差与修正LLM as a judge: biases and fixes

评委看两个答案，说哪个更好。真实的大模型评委被测出偏爱先出现的答案（位置偏差）和更长的答案（冗长偏差）。这里的评委是模拟的：感知分 = 真实质量 + 冗长系数 × log(长度) + 噪声，第一个答案额外加分。拖动滑块，在浏览器里对 3000 对答案重新评判。 A judge sees two answers and says which is better. Real LLM judges have been measured to favour the answer shown first (position bias) and the longer one (verbosity bias). This judge is simulated: perceived = true quality + verbosity × log(length) + noise, plus a bonus for the first answer. Drag the sliders to re-judge 3,000 pairs in your browser.

竞技场评分：Elo 与 Bradley-TerryArena ratings: Elo vs Bradley-Terry

8 个模型、若干张两两投票（Chatbot Arena 的做法）。在线 Elo 按比赛顺序逐场更新，同样的票换个顺序结果就不同；Bradley-Terry 一次性拟合所有票，与顺序无关。点“打乱顺序”看看。 8 models and a set of pairwise votes (as in Chatbot Arena). Online Elo updates game by game, so the same votes in another order give different ratings; Bradley-Terry fits all votes at once, regardless of order. Press “shuffle the order”.

4污染：测试题泄漏进训练数据Contamination: test questions in the training data

基准：200 道两位数乘法（答案倒着写，小模型更好学）。另取 200 道同分布的“新题”，任何模型都没见过。同一个小 GPT 用 3000 道其他题训练，再把基准题混进训练数据 0–8 次。下面的结果都是真实训练出来的。 The benchmark: 200 two-digit multiplications (answers written backwards, which a small model learns more easily). Another 200 “fresh” problems from the same distribution are never seen by any model. The same small GPT trains on 3,000 other problems, with the benchmark mixed into its data 0–8 times.
