64 个块，每块 16 个词元。“预留”模式下每个请求一来就按最大长度（256 词元 = 16 块）占位，用不完的部分（浅色）也不能给别人；“分页”模式按实际长度一块一块地分配；“分页 + 前缀共享”时，所有请求共用同一段 32 词元的系统提示词（2 块，引用计数显示在块上）。 64 blocks of 16 tokens. 3模型放不下一张卡：张量并行与流水线并行When the model doesn't fit one GPU: tensor and pipeline parallelism

张量并行（TP）把每一层的矩阵切开，每张卡算一部分，每层要做 2 次 all-reduce 合并结果，所以只适合放在 NVLink 连接的同一台机器里。流水线并行（PP）把不同的层放到不同的卡上，只在相邻阶段之间传激活值，通信少，但有“气泡”：流水线没填满时有的卡在空等。数据并行（DP）就是多放几份完整副本，各自服务不同的请求。MoE 模型还有专家并行（EP），见第 15 章。 Tensor parallelism (TP) splits every layer's matrices so each GPU computes a part; every layer needs 2 all-reduces to combine results, so it belongs inside one NVLink-connected machine. Pipeline parallelism (PP) puts different layers on different GPUs and only passes activations between neighbouring stages: little communication, but “bubbles” where some GPUs wait while the pipeline fills. Data parallelism (DP) simply runs more full replicas serving different requests. MoE models add expert parallelism (EP); see chapter 15.
