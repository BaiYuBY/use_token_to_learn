## 怎么学

每一章都按同一个节奏展开：

1. **🎮 先玩交互演示**：拖滑块、点按钮，先建立直觉
2. **📖 再读讲解**：直觉 → 图解 → 公式 → 代码 → 常见误区 → 自测
3. **🧑‍💻 最后跑代码**：用最小的 PyTorch 实现，与官方实现逐位对比
