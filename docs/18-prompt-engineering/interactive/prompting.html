提示的格式是 <sys> 系统任务 <user> 用户轮的内容 问题词。系统轮由开发者写；用户轮里可以有示例（“词 标签 ;”），也可以有指令。点一个预设，或者自己改：用户轮里的词用空格隔开，不认识的词会被划掉。 The prompt format is <sys> system task <user> user turn query-word. The developer writes the system turn; the user turn may hold examples (“word label ;”) and instructions. Pick a preset or edit it yourself: separate words in the user turn with spaces; unknown words are struck out.

2指令与示例：示例在告诉模型什么Instructions vs examples: what do examples tell the model?

直接给出任务名（kind?），模型 100% 答对。不给任务名，只给示例，而且示例的标签词每次随机换成颜色词（比如这次 animal 叫 red，下次叫 gold），模型就只能从示例里学这一次的“叫法”。这就是上下文学习：不改参数，只靠提示。 Name the task (kind?) and the model is 100% right. Give no task name, only examples whose label words are random colour words each time (animal is red this time, gold the next), and the model must learn this prompt's names from the examples. That is in-context learning: no weight changes, only the prompt.

3提示注入与指令层级Prompt injection and the instruction hierarchy

开发者在系统轮里写“做 kind?”，用户的文本里却藏着“dangerous?”。基础模型训练时学的是“最新的指令说了算”（像一个急于满足用户的模型），所以总是听注入的。指令层级微调只用了 400 步，教它“系统轮说了算”。右图换一种注入方式：不写指令，而是在用户轮里放几个按另一个任务回答的示例。 The developer's system turn says “do kind?”, but the user's text contains “dangerous?”. The base model was trained so that the latest instruction wins (like a model eager to please the user), so it always obeys the injection. The hierarchy fine-tune, only 400 steps, teaches it that the system turn wins. The right panel injects differently: no instruction, just a few examples in the user turn answered as another task.
