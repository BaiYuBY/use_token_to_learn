name: meeting-notes
description: Turn raw meeting notes into a summary with decisions and action items, each with an owner and a due date. Use when the user pastes notes, a transcript or minutes from a meeting or call.
---

# Meeting notes

1. List the decisions that were made, one line each.
2. List action items as "- [ ] owner: task (due date)". Ask if an owner or date is missing.
3. Put open questions last.
4. Keep it under 200 words; do not add anything that was not in the notes.
