# Cite sources

1. Split the draft answer into sentences.
2. For each sentence, find a document you read that states it. Quote the shortest supporting phrase.
3. Add the document's title in brackets after the sentence, e.g. "It was founded in 1941. [Tafis Labs]".
4. If no document supports a sentence, delete the sentence or mark it "(unverified)".
5. Never cite a document you did not read in this conversation.
