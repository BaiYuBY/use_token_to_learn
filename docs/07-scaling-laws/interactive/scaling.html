模型多大、数据多少、算力怎么分？损失随规模的变化惊人地有规律。本页的实验数据来自本章代码在 CPU 上的 20 次真实训练。 How big a model, how much data, how to split the compute? Loss changes with scale with surprising regularity. The experimental data on this page comes from 20 real training runs of this chapter's code on a CPU.

1幂律：在双对数坐标里是一条直线Power laws: a straight line on log-log axes

L(x) = E + A·x−α。规模 x 每扩大 10 倍，可约减的那部分损失（L − E）就缩小为原来的 10−α。E 是“不可约损失”，数据本身的不确定性，再大的模型也降不下去。切换坐标轴看看：在普通坐标下像是“越来越没用”，在双对数坐标下是稳定的直线。 L(x) = E + A·x−α. Every 10× in scale x shrinks the reducible part of the loss (L − E) by a factor of 10−α. E is the “irreducible loss”, the uncertainty in the data itself that no model can remove. Switch the axes: on linear axes it looks like “diminishing returns”, on log-log axes it is a steady straight line.

2Chinchilla：给定算力，模型和数据怎么分？Chinchilla: how to split a compute budget between model and data

训练算力 C ≈ 6ND。同样的 C，可以训练大模型、少数据，也可以训练小模型、多数据。曲线是沿着这条“等算力线”预测的损失，最低点就是算力最优。默认用 Besiroglu 等人 2024 年重新拟合的参数；也可以切换回原论文发表的参数，结果差别很大。 Training compute is C ≈ 6ND. The same C can train a big model on little data or a small model on lots of data. The curve shows predicted loss along this iso-compute line; its minimum is the compute-optimal point. The default uses Besiroglu et al.'s 2024 refit; you can switch to the parameters published in the original paper, and the answer changes a lot.

3我们自己的 isoFLOP 实验Our own isoFLOP experiment

在 Python 标准库的源代码上做字符级训练。每个算力预算下训练 5 个不同宽度的模型（都恰好花掉同样的算力），共 20 次。每条曲线都是 U 形：模型太小学不动，太大则看的数据太少。★ 是抛物线拟合出的最低点。 Character-level training on the Python standard library's source code. For each compute budget, 5 models of different widths are trained, each spending exactly that budget: 20 runs in total. Every curve is U-shaped: too small a model cannot learn enough, too large a model sees too little data. ★ marks the minimum of a fitted parabola.

4用小实验预测大实验，准吗？Can small runs predict a bigger one?

Scaling Laws 最大的用处，是先用小模型拟合规律，再预测昂贵的大模型。这里只用前 3 个算力预算的 15 次实验拟合 L(N, D)，然后预测最大预算（3e12）的 5 次实验。 The main use of scaling laws is to fit the trend on small models and then predict an expensive big one. Here L(N, D) is fitted only on the 15 runs from the three smaller budgets, then used to predict the 5 runs at the largest budget (3e12).

5把推理成本也算进来Counting the cost of serving too

Chinchilla 只最小化训练成本。但模型上线后每生成一个词元要花约 2N 次运算。如果要达到同样的损失、又要服务很多用户，更划算的做法是：用更小的模型、更多的数据多训练一会儿。设定目标损失和预计的推理总量，看总成本最低的模型有多大。 Chinchilla minimizes training cost only. Once deployed, each generated token costs about 2N operations. To reach the same loss while serving many users, it pays to train a smaller model on more data. Set a target loss and the expected inference volume and see which model size minimizes the total cost.
